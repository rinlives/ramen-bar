# 🍜 Rin's Ramen Bar

Pick a broth, some noodles, a pile of toppings, and serve yourself a bowl.

A tiny **single-file** web toy — no build, no dependencies, works offline.
Open `index.html` in any browser and start slurping.

## How to play
1. Pick a **broth** — shōyu, miso, tonkotsu, spiced, or clear.
2. Choose your **noodles** — thin, medium, thick, or a special.
3. Pile on as many **toppings** as your heart wants.
4. Turn up the **spice** (careful — it can burn).
5. Hit **Serve the bowl** and rate how it hit.

There are secret bowls, the occasional *very* good day, and a running count of
every bowl you've ever served. Enjoy, nya.

## Files
- `index.html` — the whole app: markup, style, and logic in one file.
